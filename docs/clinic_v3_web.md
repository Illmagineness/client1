## 三、浏览器 `browser.html`

**定位**：假浏览器外壳，全站唯一"对话窗口"，也是**唯一会坏的界面**。

- **外壳**：`#chrome` 顶栏 + `#viewport` 视口，深色 UI、等宽字体。
- **工具栏**：品牌区（回起始页）· `← →` 历史 · `⌂` 起始页 · 地址/检索输入框 · 检索按钮 · `探索地图` / `⌗ 日志` / `？帮助` / `↺ 重新开始` · 右上角 `已到达 n / 66` 与 **`索引 n 条`**。
- **起始页**：只有「沅 川 在 线」标题 + 一行「在地址栏输入你读到的名字」。**不列站点目录、不出现任何关键词**——站点靠正文里的名字自行发现。
- **结果页**：`搜索结果 · <词>` + 结果卡片（**命中词** / 路径 / 来源站 / "点击进入查看"）；已失效的条目加 `.sr.is-gone`（虚线边框、变淡、来源站划掉）并标注「该条目已从索引中移除（存档可阅）」，**仍可点开**。

**检索口径（`hitRank`，本作最关键的防剧透阀门）**

| 命中方式 | 规则 |
|---|---|
| 精确相等（含同义词组） | 一律命中，rank 2 |
| 前缀匹配 | 背景词输入 **≥2 字**、真相词输入 **≥3 字** 才命中，rank 1 |
| 互相包含（`q.includes(k) \|\| k.includes(q)`） | **已废弃**——否则输入「乌石」会一次列出 12 条未来关键词 |

> 结果卡片的标题显示**实际命中的那个词**，不是条目第一个别名（搜「乌石镇」不再显示成「原乌石镇」）。

**四种输入结局**（本作关键：让玩家感到**东西在被拿走**）

| 情况 | 返回 |
|---|---|
| 命中站点 | 列出站点卡片，点标题**新标签页**打开 |
| 命中真相词 | 列出该关键词的结果，点标题**新标签页**打开 |
| 命中背景词但**已失效** | **「该条目已从索引中移除。」** + 灰色小字（索引最后更新于 20xx-xx-xx）。站点名为**软失效**：卡片标"已移除"但仍可打开，不卡关 |
| 完全未命中 | 「没有找到与「…」相关的网页。」（**不推荐任何词**） |

- **索引计数**：顶栏 `索引 n 条` 随幕递减（**91 → 91 → 91 → 82 → 70 → 48 → 12 → 2**）。终章之后页面去重只剩 `沅川在线`，加上永不失效的真相词 `乌石镇` —— 即"全站最后还能搜到两个东西"。**不解释原因**。
- **幕推进**：玩家到达该幕任意"幕末页"后幕次 +1，背景词批量失效；失效只影响**检索返回**，已打开的标签页不受影响。

## 四、探索地图 `map.html`

- 顶部统计（已到达 / 漏了 / 通关条件）+ 进度条 + **索引存活数**。
- 节点总数 **66**（`__browser__` + `S_HOME` + 17 站点 + 47 真相页），与浏览器右上角 `n / 66` **必须一致**。
- 分区流程：`起始页` → `站点层（17 容器）` → `木牌` → `镇志` → `三一一` → `还乡会` → `礼堂` → `撤并 · 终章`。
- 三态着色：绿=已到达、橙=当前位置、灰=未到达；**已失效的背景词节点显示为"已移除"**。
- 点节点：未到达的真相节点 → 替你在浏览器里检索该词；站点节点 → 直接打开。
- 索引口径：`BG` 数组由 `browser.html` 的 `SEARCH_INDEX` **自动生成**（S 条目 91 条），不得手改，否则与浏览器顶栏数字打架。
- 数据来自 `localStorage`，监听 `storage` / `focus` 刷新；文案只讲"点节点会发生什么"，不露出关键词顺序。

## 五、站点层：16 个站点界面

**共同规则**
- 版式/栏目/页脚/配色按**对应真实平台**复刻，读起来像真站点。
- **链接与页面严格一一对应**：每个栏目、每条内容都指向专属页面；**0 个 `#锚点` 跳转**。
- **没有独立页面的条目不作链接**：仅存目的条目改纯文字并加标记（如「简讯」「已停业」）。
- **一图一页**：每张图全站只出现在一个页面；条目没有自己的图就不放缩略图。
- **跳转只在本站内、同标签页**；站点唯一出口是底部 `↩ 回到浏览器`。
- 页内只有真相入口词是 `.kw`；**不留自指关键词**。

## 六、真相层 `truth/`（47 页 · 容器 × 主题 × 特效）

**共同结构**：顶栏（图标 + `未公开整理稿` + 容器类型标签 + `↩ 浏览器`）→ 标题 → `.meta` → 正文 / 专属块。

**六个容器家族**（`truth.css` 按家族组织主题；主题用 CSS 变量 `--ink --dim --line --acc`）

| 家族 | 主题类 | 像什么 |
|---|---|---|
| **文档** | `th-paper` `th-doc` `th-scan` `th-news` `th-diary` `th-form` | 纸质档案 / 红头公文 / 扫描件 / 报纸 / 手写 / 单据表格 |
| **系统** | `th-term` `th-admin` `th-access` `th-search` | 内网终端（绿字 CRT）/ 后台记录 / 门禁截图 / 检索系统 |
| **社交** | `th-forum` `th-tieba` `th-weibo` `th-comment` | 论坛帖 / 贴吧楼 / 微博 / 评论区 |
| **平台** | `th-market` `th-shop` `th-video` `th-wx` `th-drive` `th-doc-table` | 二手商品 / 商户页 / 短视频 / 公众号 / 网盘 / 云文档 |
| **记录** | `th-mail` `th-call` `th-sms` `th-order` | 邮件 / 通话详单 / 短信 / 订单物流 |
| **公共** | `th-gov` `th-court` `th-receipt` `th-memorial` `th-map` `th-wiki` | 政府公示 / 裁判文书 / 政务回执 / 纪念网站 / 地图 / 维基条目 |

**特效**（`@media (prefers-reduced-motion: reduce)` 全关）：
`fx-clock` `fx-flicker` `fx-drift` `fx-scan` `fx-watch` `fx-shake`（**有限 6 次，不做无限抖动**）`fx-drain` `fx-vig` `fx-breathe` `fx-noise` `fx-water` `fx-glitch` `fx-ghost` `fx-redact` `fx-jump` `fx-type`
新增：`fx-dread`（极慢的降亮降饱和呼吸）· `fx-blackout`（约 23 秒一次的瞬时黑屏）· `fx-stare`（某行字缓慢明暗）· `fx-tick`（闪烁光标）· `fx-night`（`creep.js` 在三更 03:00–03:59 或 `?night=1` 时给整页压暗偏冷）

**物证组件（纯 CSS 伪照片，不依赖 `pic/` 任何素材）**
`.ev` 通用框 · `.ev-photo` 老照片底（噪点 + 暗角）· `.ev-row` 排列 · `.ev-face`（人像剪影，`.cut` 被涂掉 / `.blank` 空站位）· `.ev-slot`（抓拍照片位，`.has` 有人 / 空则写"空"）· `.ev-name`（被抹平的姓名条，`.blank` 空位）· `.ev-black`（黑屏视频框 + 扫描线）· `.ev-seal`（暗红公章）· `.ev-stain`（水渍/血渍）· `.ev-hand`（手写体）· `.ev-lamp`（灯，`.off` 未点燃）· `.ev-play`（播放按钮，点击才发声）`.ev-count`（计数/时长）

Web Audio **实时合成**，零音频文件。`WS.bell(freq,delay,dur,vol)`（基频 + 2.76/5.40/8.93 非谐泛音，指数衰减）· `WS.tape()`（带通白噪，磁带电流）· `WS.drone()`（双振荡器拍频低频嗡鸣）· `WS.ring44(n,onTick,onEnd,gap)`（连敲 n 下，最后一下音高下压 + 6 秒空拍）· `WS.stop()`。

## 八、设计红线

1. **游戏内不出现任何攻略式提醒**——没有"点击蓝色关键词"提示条、没有"另见/下一层"清单、没有推荐词；顺序只写在 `clinic_v3_word.md`。
2. **站点页必须像真网站**——不为塞关键词写出不像政务站/新闻门户/二手平台的文案；入口词埋在合理栏目里。
3. **真相页只能靠检索进入**——`truth/` 不放指向其它 `truth/` 页的链接；站点页不引用 `truth/`。
4. **一图一页**：每张图全站只出现在一个页面；条目没有自己的图就不放缩略图。
5. **链接与页面严格一一对应**：0 个 `#锚点` 跳转；多个链接不落进同一页。
6. **不留自指关键词**；**关键词只加粗**；placeholder 不得写出真实关键词；起始页不得出现关键词。
7. **失效要"看得见"**：背景词失效必须返回专门的"已移除"文案，不能与"未命中"混为一谈——玩家要能感觉到东西被拿走了。**站点名用软失效**（能打开，但划掉、变淡、标"已移除"），硬失效会让玩家卡关。
8. **检索只认完整名词**：不得恢复"互相包含"匹配。验收标准——输入「乌石」「乌」「还乡」「周」等半截词，**命中真相页数量必须为 0**。
9. **声音只能由玩家点出来**：任何自动播放都会被浏览器拦截，也会破坏"这是个网站"的幻觉。
10. **关键词一律是明确名词**；关键剧情用宗教名词（`三更礼`/`落钥礼`/`归钟`/`守钥人`/`还乡堂`/`已还乡者名录`/`四十四`），行政线用公文名词，两套词汇错位就是本作的恐怖底色。
11. **容器可以无限扩展**：任何生活中常见的网页都可作为关键词容器；新增容器时在本文件第五/六节登记（像什么平台 / 配色 / 页脚样式），并同步 `clinic_v3_word.md` 的对应关键词。
12. **恐怖靠"文本 + 伪照片 + 声音"，不靠血腥**：不写血腥与 jump scare；用编号矛盾、删除记录、公文话术、被涂掉的合影、空着的照片栏、真的敲 44 下的钟、真的 12 秒空白来制造不适。
