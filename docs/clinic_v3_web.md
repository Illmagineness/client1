## 二、浏览器 `browser.html`

- 顶栏：`← →`（页内历史）· `⌂`（起始页）· 地址/搜索栏 · `？帮助` · `↺ 重新开始` · 进度计数 · `探索地图`（打开 `map.html`）。
- 起始页：只有「怀安在线 · 本地导航」四个站点卡片（**无使用说明、无快捷入口提示**）。
- 行为：

| 输入 | 行为 |
|---|---|
| 站点名（档案馆 / 新闻主页 / 贴吧主页 / 公众号主页 / 博客） | **新标签页**打开该站首页 |
| 任意关键词 | 本页列出**搜索结果**（一一对应，通常一条）；点结果标题在**新标签页**打开对应网页 |
| 未命中 | 显示"没有找到与「…」相关的网页。"（**不推荐任何词**） |

## 三、路由机制

1. `SEARCH_INDEX`（`browser.html`）：关键词（含同义词数组）→ 页面 id。
2. `PAGE_ROUTE`（`browser.html` / `assets/nav.js` / `map.html` 三处保持一致）：页面 id → `[文件, 锚点]`。路径均为**相对项目根**，如 `sites/news/index.html`、`truth/act1/t01-oldfile.html`。
3. 打开：`window.open(文件 + '?node=' + id + '#锚点')`。
4. **进度上报**：页面加载 `assets/nav.js` → 读 `?node=` → 写入 `localStorage['huaian1998_v3'].f`。
5. **相对路径自适应**：`nav.js` 通过自身 `document.currentScript.src` 反推项目根（`<root>/assets/nav.js`），据此计算当前页相对根的路径与 `../` 前缀——任意层级页面都无需硬编码。
6. **无参数兜底**：按「相对根路径 + 锚点」唯一匹配推断节点。
7. **关键词点击**：`.kw` → 新标签页打开 `browser.html?q=词`。
8. **跨页链接**：`a[href*=".html"]` 自动加 `target="_blank"`，原页面不覆盖。

## 四、站点层（背景容器）

- 只放氛围 / 背景词：`永宁堤`、`怀水河`、`拦河闸`、`永宁镇`、`县志`、`怀安水利志`、`渡口村`、`老照片` 等。
- **不出现任何真相词**（`结案报告`、`救生衣编号`、`卫字003`、`防汛日志`、`三人名单`… 只在 `truth/` 出现）。
- **唯一入口**：`sites/archive/index.html` 的「数字化项目 · 正在进行」卡片里的 `旧档补录`（点击 → T01）。
- **结构（照真实站点重做）**：
  - `sites/archive/` —— 政务 / 档案信息网式：顶部服务条（无障碍 / 长者版）→ 站头 + 站内搜索 → 横向栏目导航 → 要闻大图 + 通知公告 → 馆藏专题 / 数字化项目 → 快捷服务 → 政务页脚。
  - `sites/news/` —— 地方新闻门户式：日期 / 天气条 → 红色报头 + 版面导航 → 头条大图区 → 图文新闻列表（左图右文）→ 热点榜 / 专题侧栏 → 版权页脚。
  - `sites/tieba/` —— 贴吧式：顶部蓝条 + 吧内搜索 → 吧头（关注 / 签到）→「看帖」表格列表 → 楼层卡片（头像 / 等级 / 楼中楼）→ 吧务侧栏 → 分页。
  - `sites/wx/` —— 微信公众号文章式：手机外壳 + 状态栏 → 顶栏 → 公众号名片 → 历史消息分组列表 → 文章正文（17px / 行高 1.75）+ 留言区 → 底部导航 + 号内搜。
  - `sites/web/` 与 `sites/blog/` —— 旧站镜像 / 个人博客式。
- **锚点固定（改结构时不得删）**：`news` 的 `#dike / #photos / #report / #culture`；`tieba` 的 `#story / #dike / #chat`；`wx` 的 `#dike / #photo / #memory`；`archive` 的 `#hold / #doing`；`blog` 的 `#ferry / #lamp`。

## 五、真相线 `truth/`

- **一词一页**，同义词合并；按 Act 分目录（act1–act6），无锚点依赖。
- 顶栏统一：`未公开整理稿` + 类型标签 + `↩ 浏览器`（**无层级进度标签、无底部提示条**）。
- 页脚一律是叙事文字（不再是"另见：…"清单）。
- 风格：纸质档案 / 公文 / 病历 / 值班横格纸 / 绿字 CRT 内网 / 论坛 / 家庭 / 照片查看器 / 录音波形 / 物证标签 / 数据表 / 名单 / 报纸 / 手写日记 / 广播 / 地图 / 通告 / 遗物；图片位 `.viewer > figure > img + figcaption`（任何主题可用，缺图自动隐藏）。
- 特效：故障字、闪烁、涟漪、扫描线、噪点、晕影、被注视、幽灵字、打字机、涂黑可擦、页面自动褪色（`t46` 起脚本按时间改页面）。
- `@media (prefers-reduced-motion: reduce)` 关闭全部动画。

## 七、可达性

- 每个页面 id 都能在 `PAGE_ROUTE` 找到文件且文件存在；站点内无指向已删旧页的链接。
- `browser.html` / `assets/nav.js` / `map.html` lint 0 错误。
