## 一、故事设定

### 1.1 地点与时间

| | |
|---|---|
| 玩家所在 | 2026 年 9 月 |
| 城市 | **沅川市**（虚构地级市，南方沿江，老工业底子） |
| 县 | **柳津县**（下辖柳津镇、乌石镇等） |
| 核心地点 | **乌石镇**——2016 年 3 月撤并，并入柳津镇；网上的痕迹正在被一条条清掉 |
| 水系 | **柳溪河**（乌石镇在柳溪河下游弯道，镇口一座石桥，桥头一座礼堂） |

| 时间线 | 2009 还乡会成立 → **2016-03-11 三更礼** → 2016-03-18 撤并批复 → 2026 玩家进场 |

### 1.2 一句话主线

2026 年，你在本地导航站「沅川在线」闲逛，在二手平台看到一块 50 元的旧木牌，背面刻着一枚**倒钥匙**。
顺着这块木牌，你会找到一个**搜不到的镇**、一场被称为"外出务工"的集体离开、一个叫**还乡会**的组织，以及**点名册上的第四十四行**。
——你要在搜索索引把乌石抹干净之前，把这个镇拼回来。

## 二、两类关键词

### 2.1 定义与差别

| | **背景关键词** | **真相关键词** |
|---|---|---|
| 数量 | **40 个**（开局全部可用） | **47 个**（一词一页） |
| 词性 | **一律是明确名词**——地名、单位名、店名、路名、文种名 | **一律是明确名词**；其中 10 个为带宗教色彩的复杂名词 |
| 所在 | 只存在于**浏览器检索索引**，页面正文里**不加粗** | 站点页与真相页正文里**加粗**（`.kw`） |
| 点击行为 | 只能在浏览器地址栏输入 | 点一下 → 回浏览器自动检索 → 点结果进真相页 |
| 作用 | 让沅川/柳津像一座真城市一样可逛、可搜、"有生活" | 逐层推进，揭开乌石镇 |
| 结局 | **随幕失效，最后只剩 2 个** | 走到终章，成为唯一还能搜到的东西 |
| 定义位置 | `browser.html` 的 `SEARCH_INDEX`，`p` 为 `S*` | `browser.html` 的 `SEARCH_INDEX`，`p` 为 `T*` |

**命名铁律**

1. **只收明确名词**。不写"凌晨三点""地图上没有的路"这类短语——要写成 `三更`、`乌石便道`。
2. **一词只指一物**。同义词组合并到一页（如 `倒钥匙 / 倒置的钥匙`）。
3. **关键剧情用宗教名词**。还乡会的术语自成一套（见附录 九），这些词本身就是恐怖来源：`三更礼`、`落钥礼`、`归钟`、`守钥人`、`已还乡者名录`、`还乡堂`、`四十四`。
4. **官方口径用公文名词**：`乡镇撤并批复`、`外出务工名单`、`刑事裁定书`、`政务热线回执`、`信访答复`、`施工许可`、`门禁记录`、`通话详单`、`第四十四行`。
   —— 一半是行政名词、一半是宗教名词，两套词汇互相错位，就是本作的恐怖底色。

### 2.2 背景词：开局很多，随幕失效（本作的核心节奏）

开局一次性放出 **40 个背景词**，玩家可以像逛真网站一样随便搜、随便看。**这一层是"这座城市活着"的证据**。

| 幕 | 结束时可搜到 | 失效时的检索返回 |
|---|---|---|
| 幕一 · 木牌 | 40 | — |
| 幕二 · 镇志 | 40 | — |
| 幕三 · 三一一 | 31 | 9 个条目**从索引中移除** |
| 幕四 · 还乡会 | 21 | 又 10 个 |
| 幕五 · 礼堂 | 10 | 再 11 个（站点停止服务 / 公众号注销） |
| 幕六 · 撤并 | 3 | 再 7 个 |
| 终章之后 | **1**（`沅川在线`；真相词 `乌石镇` 永不失效） | 其余全部"没有找到与「…」相关的网页。" |

**设计意图**：玩家的检索能力在**退化**。开局资源最多、越到后面越穷——他必须在"还搜得到"的时候把该看的看了。恐惧不来自怪物，来自**能搜到的东西一天比一天少**。

失效的游戏内解释（三条并行，不点破是哪一条）：① 乌石镇被撤并，行政区划条目被系统性归档；② 平台数据治理与站点关停；③ 还乡会在清理痕迹。

### 2.3 真相关键词：47 个，一词一页

一条关键词**只对应一个网页**；页内 `.kw` **只能是真相词**（背景词不上页面）；真相页之间**不放任何链接**，只能靠检索进入。

按幕分布：**4 / 7 / 8 / 11 / 10 / 7**。

## 三、六幕结构

| 幕 | 词范围 | 主题 | 玩家在做什么 | 调性 |
|---|---|---|---|---|
| **一 · 木牌** | T01–T04 | 引子 | 在二手平台闲逛，被一块木牌勾住 | 日常 · 只有一点点不对劲 |
| **二 · 镇志** | T05–T11 | 这个镇是什么、怎么没的 | 查镇志、查撤并、查老照片 | 档案的缺口开始扎眼 |
| **三 · 三一一** | T12–T19 | 2016 年 3 月 11 日 | 拼当年到底走了多少人 | 数字第一次对不上 |
| **四 · 还乡会** | T20–T30 | 组织与教义 | 弄清"还乡"是什么意思 | 仪典恐怖成形 |
| **五 · 礼堂** | T31–T40 | 物证 | 进礼堂、下地窖、听钟 | 页面开始动 |
| **六 · 撤并** | T41–T47 | 终章 | 把第四十四行拼出来 | 页面自己消失 |

**幕末钩子**
1. 木牌 → 卖家："你要找的那个镇，网上已经没有了。"
2. 镇志 → 镇志在 1987 年之后**整段缺页**，缺页处夹着一张 2016 年的报纸。
3. 三一一 → 通报附件写着 43 人，但名单排版里**有一行空着**。
4. 还乡会 → 教义最后一页："还乡不是回来，是不再外出。"
5. 礼堂 → **归钟敲了 44 下**。
6. 撤并 → 你正在浏览的页面开始一行行消失。

## 八、检索与进度规则

- **匹配**：精确相等 / 输入包含关键词 / 关键词包含输入；命中多条按匹配度排序；同义词组映射到同一页。
- **一一对应**：一条关键词只对应一个网页。
- **点击**：页面上的 `.kw` **只加粗**（无主题色、无虚线、无悬停反白、无 `title`）；点一下新标签页打开浏览器并自动检索；点结果标题新标签页打开网页；原页面始终保留。
- **未命中**：「没有找到与「…」相关的网页。」（**不推荐任何词**）
- **已失效**：「该条目已从索引中移除。」（与"未命中"区分，让玩家明确感到**东西被拿走了**）
- **进度**：`NODE_IDS` = 起始页 + 站点页若干 + `T01`–`T47`；顶栏 `已到达 / N` + `索引 40 条`（随幕递减）。
- **通关**：到达 `T47 撤并`。**清空**：顶栏「↺ 重新开始」。

## 十、附录 · 真相与终章

**表面真相**
2016-03-11 凌晨三点，还乡会在乌石礼堂（还乡堂）举行三更礼。点名时 43 人应答，随后集体离开。为免被定性为"事件"，镇里抢先把通报写成《乌石镇 43 名群众外出务工，已取得联系》（2016-03-13），五天后再以行政区划调整把乌石镇撤并（2016-03-18）。此后再无人提乌石。

**深一层真相**
**周砚生是点名时唯一没有应答的人。** 他是播音员，也是会里的**守钥人**（教义规定守钥人不能外出）。3 月 10 日他录下最后一期广播、写了一封没发出去的求助信，3 月 11 日 02:41 刷卡进小学、03:02 拨出一个 0 秒的电话——他没能拦住。
而因为通报的口径是"43 人"，名单排版占了 44 行，**多出来的那一行必须填一个名字**。于是他被填进去，并从编制、学籍、社保、校友录里逐项抹掉。

**恐怖内核**
抹掉他的不是还乡会，是**归档流程**。他成了"第四十四行"——一个为了让公文自洽而存在的名字。

**终章（T47 撤并）**
玩家把第四十四行拼出来。页面开始一行行自我撤并：栏目消失、页脚消失、检索框消失；最后还剩两个能搜的词：`沅川在线` 与 `乌石镇`。输入 `乌石镇`，返回的是那条"待核"维基条目，正文只有一句：
> 乌石镇，见柳津镇。
