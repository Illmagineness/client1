## 一、两类关键词

| | **背景词** | **剧情词** |
|---|---|---|
| 数量 | 17 组 / 25 个词串（含同义词） | 52 组（**一词一页**，同义词合并） |
| 所在 | 站点网页正文 | 真相页正文 |
| 点击行为 | **直接打开**对应网站页面（带锚点定位板块） | **回浏览器检索** → 点结果链接 → 打开真相页 |
| 作用 | 氛围、地情背景、"呼吸" | 逐层推进，揭示真相 |
| 定义位置 | `assets/nav.js` 的 `KW_BG` 表 | `browser.html` 的 `SEARCH_INDEX`（`p` 为 `T*`） |

**交替结构（本作的核心节奏）**

- **站点层**：以背景词为主，同时**埋入剧情入口**——每个站点都挂着自己的剧情线（可多条）。
- **真相层**：以剧情词为主，`nav.js` 自动把正文里出现的地情名变成背景链接，做节奏呼吸。
- 于是玩家在"读背景 → 追剧情 → 退回背景 → 再追剧情"之间往返，而不是一条直线紧绷到底。

## 六、检索与进度规则

- **匹配**：精确相等 / 输入包含关键词 / 关键词包含输入；命中多条按匹配度排序。
- **一一对应**：一条关键词只对应一个网页；同义词组映射到同一页。
- **点击**：站点页与真相页正文里的关键词都是加粗标记（`.kw`）。背景词直接跳页；剧情词在新标签页打开浏览器并自动检索，点结果标题在新标签打开对应网页。原页面始终保留。
- **未命中**：结果页显示"没有找到与「…」相关的网页。"（不给任何推荐词）。
- **跨标签同步**：`browser.html` 监听 `storage` 事件，多标签页进度实时同步。

1. **每个 `.kw` 必须能解析**：要么在 `KW_BG`（背景词 → 直达），要么在 `SEARCH_INDEX` 且映射到 `T*`（剧情词 → 检索）。否则点击会落到"没有找到"。
2. **`PAGE_ROUTE` 三处必须一致**：`browser.html`、`assets/nav.js`、`map.html`。
3. **关键词网页只能靠检索进入**：`truth/` 页面里不放任何指向其它 `truth/` 页的 `<a href>`；站点页也不引用 `truth/`。
4. **站点页同时要有背景词和剧情词**，真相页同时要有剧情词和背景词——维持"两层往返"。
5. **不新增节点时**，`NODE_IDS`、`PAGE_ROUTE`、`SEARCH_INDEX`、`map.html` 的 `NODES` / `NODE_OPEN` / `MAIN_PATH` 四处要同步增删。
6. **不留自指链接**：某页正文里指向**自己这一页**的关键词要去掉 `.kw`（带锚点的同页导航除外）。
7. **改完回来同步本文件**。
