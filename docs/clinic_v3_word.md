# 怀安在线 · 关键词总表与「出现顺序」

> **结构**：① 浏览器 `browser.html`（检索中枢）　② 四大站点 `sites/archive/` `sites/news/` `sites/tieba/` `sites/wx/`（**初期背景容器**）　③ 散落的旧网页 `sites/web/` + 博客 `sites/blog/index.html`　④ 真相线 `truth/`（**52 个独立页，一词一页**）
> **核心规则**：**关键词 ↔ 网页 一一对应**（一组同义词 = 一个独立网页）；搜索 → 弹出一条结果链接 → 点开在**新标签页**打开对应网页。
> **游戏内不出现任何提醒**（无"另见/下一层/点击关键词/推荐主线"等提示）。**关键词的先后顺序只记录在本文件里**，供设计参考。
> 网页与交互结构见 `clinic_v3_web.md`；叙事与设定见 `clinic_v3_design.md`。

## 六、检索规则

- **匹配**：精确相等 / 输入包含关键词 / 关键词包含输入；命中多条时按匹配度排序。
- **一一对应**：一条关键词只对应一个网页；同义词组映射到同一页。
- **点击**：站点页 / 真相页正文里的关键词为加粗标记（`.kw`），点一下即在**新标签页**打开浏览器并自动检索该词；浏览器页列出搜索结果，点结果标题在**新标签页**打开对应网页。原页面始终保留。
- **未命中**：结果页显示"没有找到与「…」相关的网页。"（不再给任何推荐词）。
- **进度**：浏览器打开网页时附带 `?node=<页面 id>`，页面 `nav.js` 把该 id 写入 `localStorage['huaian1998_v3']`，探索地图与浏览器同步。
- **清空进度**：浏览器顶栏「↺ 重新开始」。

## 七、体验约束：游戏内不出现提醒

已移除的内容（**不得再添加**）：

- 页面底部固定提示条（`.fix` / `.tip`：如"点击蓝色关键词，回到浏览器继续检索"）——**已全部删除**；
- 真相页页脚的"另见：… / 下一层：…"关键词提示——**已改写为叙事正文**（关键词仍在正文里出现，链路不断）；
- 真相页顶栏的"真相 · 第 N 层"进度标签——**已改为"未公开整理稿"**；
- 浏览器起始页的"怎么用 / 先试试"说明块、帮助浮层里的"提示 / 检索不到？"——**已删除**；
- 搜索结果未命中时的推荐词清单——**已删除**；
- 探索地图的"推荐主线"与节点"↳ 引出：…"——**已删除**（顺序只记录在本文件）。
