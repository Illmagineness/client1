# 怀安在线 · 1998 防汛失踪案（叙事 / 结构设计）

> 类型：网页解谜 / 搜词解谜（ARG 风），含**心理惊悚与超现实**层
> 玩家视角：**一个普通网友**，用浏览器在站点与真相页之间搜索、拼出那夜的事
> 关键词总表与**出现顺序**见 `clinic_v3_word.md`；网页与交互结构见 `clinic_v3_web.md`

---

## 一、核心设定

1998 年夏，怀安发了一场没被记入县志正文的洪水。三名守堤的防汛队员在决口夜失踪，县里对外统一口径："转移安置，下落待查"。二十多年后，方志馆数字化，一名归档员在"旧档补录"里发现一批互相矛盾的记录——值班日志、卫生院接诊单、论坛旧帖、家属寻人帖、一份被反复涂改的结案报告。

玩家不是侦探，只是一个**上网查资料的网友**：搜词、开网页、读到新词再搜，一层层往下挖。

**叙事基调**：归档员是**正常的归档员**。语气平稳，只说"前后说法不一致，标了待核"。真相由玩家自己拼出来，文本不主动宣告。

## 二、超现实与恐怖层（本次新增）

在原有写实档案线之上，叠加一层**始终不被明说**的东西。全程不出现血腥、自残、真人伤害；恐怖来自**错位、循环、被注视、以及页面自己变化**。

| 元素 | 埋点 |
|---|---|
| **闸没有落** | 水文建议、守闸人口述、签到表涂改、地图标注——每一环都有人"本可以"改写结局 |
| **水位自己退** | 决口后 29 分钟，无降雨、无分流、闸未落，水位自己回落（"像是它进够了，就停了"） |
| **水里有人应答** | 录音 02:11 多出一句不属于三人的问话："……你什么时候下来？"；带子上有二次录制痕迹 |
| **被抹去的不止名字** | 少掉的页码、被刮掉的登记行、被涂黑的签名格、报纸补白、照片里第四道影——凡要写名字的地方都被抹过一遍 |
| **祭江旧俗** | 渡口村旧俗：大水之年要"送一个人下水"，水才肯走。1998 年下去了三个，上来两个 |
| **每年同一天同一分钟** | 8 月 5 日 03:05：论坛空回复、随访系统自动生成预约、匿名回帖注册注销，都落在这一分钟 |
| **第四个影子** | 家属合影上的第四个人、探照灯下水面那道更深的人影 |

**处理原则**：恐怖信息不解释、不聚焦、不惊呼；只作为**档案里的异常记录**出现，让玩家自己在两页材料之间发现矛盾。

## 三、真相（设定层，供作者参考）

- 决口夜，**赵建国、孙长海、周文斌**三人下水堵口；救生衣只有两件。
- 周文斌把衣让给赵、孙，自己被卷走；下游被救，**生还但隐姓埋名**。
- 赵、孙遇难。指挥部为避责，把"遇难"改成"转移"：删帖、涂改签到表、压水文数据、改原始日志权限。
- 关键物证：**决口夜录音、水文站数据、涂改的签到表、02 号救生衣、遗物袋**。
- 超现实解释层（不明说）：水"拿到了它要的东西"；被点名的三个人，是替一个还没出生的人下去的。

## 五、三层结构

```
① 背景容器（前期）        四大站点 + 博客 + 散落的旧网页
   永宁堤 / 怀水河 / 渡口村 / 1998年洪水 / 县志 / 怀安水利志 …
   ——只讲氛围与官方口径；真相词一律不出现
                │
                │ 唯一入口：档案馆「旧档补录」
                ▼
② 真相线（中后期）        truth/ 52 个独立网页（一词一页）
   表层裂缝(9) → 卫生院·系统(8) → 指挥部·公文(10) → 家庭(8) → 物证(9) → 真相·终章(8)
   ——证据互相印证又互相拆台；越往后页面越"不对劲"
                │
                ▼
③ 终章                    三人名单 → 决口夜真相 → 生还者日记 → 生还者的后来 → 终章
```

**设计原则**

1. **背景与真相彻底分离**：站点里没有真相词，真相页里没有站点导航。
2. **一词一页**：每个关键词组对应一个独立网页，浏览器的"搜索结果 → 点开新页"就是唯一动线。
3. **不做引导**：游戏内不出现"另见 / 下一层 / 提示 / 推荐主线"等任何指路文字；顺序只写在文档里。
4. **递进不一次性给完**：每页只埋 2–3 个下一层关键词，且都写在叙事句子里。

## 六、风格与特效（`truth/truth.css`）

- **写实期**：纸质档案、官方公文、值班横格纸、HIS 病历单、剪报、公众号卡片、论坛帖（各自独立配色与字体）。
- **中后期**：绿字 CRT 内网、照片查看器（放大后多出第四道影）、录音波形（时间轴末尾冒出一句不属于三人的话）、数据表（数字自己跳）、地图（标记点位置比手绘原图多一个）、涂黑可点擦除。
- **结局期**：故障字、页面闪烁、涟漪、被注视（右上角缓慢浮现的眼睛）、扫描线、噪点、晕影、幽灵字（只在余光里显形）、打字机光标。
- **"页面自己变化"**：`t46` 起用脚本按时间推进——先后加闪烁、再降饱和、最后让幽灵字变红。
- 尊重 `prefers-reduced-motion`：开启该系统设置时全部动画关闭。

## 七、关键词设计原则

1. **专有名词优先**：工程名、编号、单据名、篇名、人名、物证编号。
2. **分散**：每页 2–3 个，不堆砌。
3. **同义词合并**：一组同义词 = 一个网页（"救生衣 / 救生衣编号"、"防汛失踪案 / 失踪案"）。
4. **真相词后置**：背景 → 篇目 → 编号单据 → 人物物证 → 真相终章。
5. **入口唯一**：真相线只从档案馆的 `旧档补录` 进入。

> 完整的"某页出现什么词 → 打开哪一页"，见 `clinic_v3_word.md` 第五章。

---

## 八、体验约束：游戏内不出现提醒

- 不出现固定提示条、页脚"另见/下一层"、层级进度标签、使用说明、推荐检索词、推荐主线、节点"引出"。
- 关键词只以**正文加粗**的形式存在（这是玩法本身的视觉线索，不是文字提醒）。
- 若确需记录顺序，写在 `clinic_v3_word.md` 里，不写进游戏。
